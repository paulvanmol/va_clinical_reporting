# SAS Visual Analytics – Clinical Trials Reporting Practice

Two hands-on modules that show how SAS Visual Analytics (SAS Viya) supports **interactive clinical review**. They are meant to sit **alongside** the validated, SAS-code-based TFLs, not to replace them.

| Module | Report | Data | Time |
|---|---|---|---|
| **1** | AE Investigation (demographics, AE severity, severe-AE drill-down, age groups, subject profile) | `data/table_AE_DM.csv` | 60–75 min |
| **2** | Cardiometabolic Safety Review (exposure, heart rate, HbA1c, lab shift, eDISH / Hy's Law, outlier detection, automated explanation) | `data/module2/*.csv` | 75–90 min |

Each exercise can be done **manually** in the VA interface or with **SAS Viya Copilot** prompts.

> ⚠️ **All data is synthetic.** It copies the structure of the public CDISC SDTM/ADaM pilot study (Xanomeline: Placebo / Low Dose / High Dose, 254 subjects) and is generated by the scripts in `scripts/`. It contains no real patient data and is for training only. Module 2 contains planted signals for teaching purposes.

## Repository layout

```
data/
  table_AE_DM.csv            Module 1 – AE joined to DM, one row per AE
  DATA_DICTIONARY.md
  module2/
    adex.csv                 Exposure – one row per subject
    adlb.csv                 Laboratory – one row per subject / parameter / visit
    advs.csv                 Vital signs – one row per subject / parameter / visit
    DATA_DICTIONARY.md
practice/
  PRACTICE.md  SOLUTIONS.md              Module 1
  module2/PRACTICE.md  module2/SOLUTIONS.md   Module 2
scripts/
  generate_data.py           Module 1 data (fixed seed)
  generate_module2.py        Module 2 data (run after generate_data.py)
  expected_results.py        Rebuilds both SOLUTIONS.md files
```

## Prerequisites

- SAS Viya with SAS Visual Analytics.
- SAS Viya Copilot (only for the Copilot path).
- SAS Visual Statistics (only for the optional model exercise in Module 2).
- Permission to import data to CAS, for example `cas-shared-default / Public`.

## Regenerate the data (optional)

```bash
python scripts/generate_data.py
python scripts/generate_module2.py
python scripts/expected_results.py     # needs pandas + tabulate
```
