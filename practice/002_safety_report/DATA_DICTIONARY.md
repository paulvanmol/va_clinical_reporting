# Data dictionary – Module 2

Labels come from the SAS transport files in `data/` (CDISC pilot ADaM, see README). Generated by `programs/04_expected_results.py`.

`ADSL` is described in Module 1. Subject-level columns (`USUBJID`, `AGE`, `SEX`, `RACE`, `TRTA`) repeat in the other tables so each table can be used on its own.

## advs

Vital signs, one row per subject × parameter × position × visit. `PARAMCD`: PULSE, SYSBP, DIABP. `ATPTN` 815 = lying, 816 = standing 1 min, 817 = standing 3 min. `AVISITN` 99 = End of Treatment (duplicates the last visit).
